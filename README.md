# Robotics Journey

Mechanical engineer — 12 years in automotive product work — pivoting into robotics, aimed at healthcare-adjacent and assistive work that makes living easier and more wholesome.

This repo is my public learning record: the path I'm following, what I'm studying, and the projects I'm building along the way. It's a record of how I learned, not just what I finished.

## How this repo is organised

- `learning-log/` — short dated notes after study sessions. This is the "how I learned" part.
- `01-math-and-physics/` through `04-pora-and-ros/` — notes, checklists and resources for each phase.
- `05-projects/` — finished and in-progress projects, each with its own README explaining the problem, the build, what broke, and what I learned.

## My rule for this repo

Small and honest beats big and polished. A five-minute log entry counts. A project with a working demo and a note about what failed counts more than a perfect-looking project with no story.

## What isn't here

Private reflections stay private and are not part of this repo. This is the learning trail only.
