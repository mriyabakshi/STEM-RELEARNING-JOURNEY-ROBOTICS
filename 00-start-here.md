# Start here

Read this once, then you can delete this file.

## Uploading this to GitHub (browser only, no terminal needed)

1. Go to github.com/new. Name the repository `robotics-journey`, set it to Public, and do not tick "Add a README" (this template already has one).
2. Unzip this starter on your computer.
3. In your new empty repo, click **Add file → Upload files**, then drag the folders and files from the unzipped folder into the page. GitHub keeps the folder structure. Click the green **Commit changes** button.
4. If a folder doesn't come across in the drag, use **Add file → Create new file** instead and type the path yourself, e.g. `learning-log/2026-11-02-my-first-entry.md`, then paste the content in.

## Your 5-minute routine after a study session

1. In `learning-log/`, copy `TEMPLATE.md` and rename the copy `YYYY-MM-DD-short-topic.md` (for example, `2026-11-02-linear-algebra-vectors.md`).
2. Fill in the five lines. Short answers are fine.
3. Commit. Done.

No daily streak is required. A weekly entry is plenty.

## Later, when you have a project to show

1. Copy `05-projects/project-template/` and rename it for your project.
2. Fill in its README, add a photo or short video/GIF of it working, and link it from `05-projects/README.md`.
3. On your GitHub profile, pin your best 3–4 projects so visitors see them first.
4. Later still, you can turn this same repo into a free personal website with GitHub Pages — no new platform needed.
